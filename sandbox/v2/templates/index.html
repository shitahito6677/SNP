About / Methodology
อ่านก่อนเชื่อตัวเลขใด ๆ ในเว็บนี้

  

    

      
Pipeline ทำงานยังไง

      
ทุกวันทำการ t: (1) execute คำสั่งของเมื่อวานที่ราคา close วัน t (Adj Close รวมปันผล) (2) หุ้นที่ไม่มีราคาแล้ว (delist) → เงินสดที่ราคาล่าสุด (3) คิดมูลค่าพอร์ต (4) A → B → C คัดหุ้นจากสัญญาณที่วันที่ ≤ t (5) ส่ง ctx ให้เงื่อนไข (process แยก) → เป้าน้ำหนักใหม่ → ซื้อขายที่ close วัน t+1 · ค่าธรรมเนียม 0.10% ต่อขา · rebalance เฉพาะวันที่เป้าเปลี่ยน

      
เว็บไม่คำนวณโมเดลเอง — อ่าน signal ที่คำนวณไว้แล้วจาก export ของแต่ละโมเดลเท่านั้น (ranking ของ Model A เทียบทั้ง universe — คำนวณจาก subset จะผิด) version ไหนไม่มีไฟล์ = "ไม่มีข้อมูล"

      
Look-ahead guard

      
process ของเงื่อนไขได้รับราคาและสัญญาณทีละวัน จึงไม่มีข้อมูลอนาคตอยู่ในหน่วยความจำเลย; ctx.history(end=อนาคต) → error; signal ทุกตัวผ่าน as-of (date ≤ t); Model A หลัง valid_through (held-out ของโมเดล) = ไม่มีข้อมูล ไม่ใช้รอบเก่าแทน · มี unit test ที่พยายามอ่านอนาคตแล้วต้อง fail

      
Held-out

      
ข้อมูลตั้งแต่  ล็อกไว้ (วันจบ default ) — ถ้าดูผลช่วงนี้แล้วกลับไปปรับเงื่อนไข = เอาข้อสอบมาติว ผลช่วง held-out จะไม่น่าเชื่อถืออีก การรันเข้า held-out ต้องเปิด toggle + พิมพ์ยืนยัน และผลติด badge HELD-OUT ถาวร

      
Reproducibility

      
ผลที่บันทึกเก็บ config + ข้อความเงื่อนไขเต็ม + git commit + data_hash ของราคา + manifest ของทุก version · เปิดผลเก่า = อ่านไฟล์ ไม่รันใหม่ · ปุ่ม Re-run เทียบตัวเลขทุกหลักและบอกสาเหตุถ้าต่าง
