# stress_cases — เคสหุ้นเจ๊งที่ผู้ใช้ใส่เอง (สำหรับทดลองระบบใน sandbox เท่านั้น)

> ## ⛔ ห้ามปนกับข้อมูลที่ใช้คัดเลือกหรือปรับกฎ
> ไฟล์ในโฟลเดอร์นี้ **ห้ามถูกอ่านโดย** `lib/`, `rounds/`, `export/build_scores.py` หรือขั้นตอนใดที่คำนวณสัญญาณ/backtest/trial
> ใช้ได้เฉพาะการทดลองว่าระบบ (sandbox/adapter) แสดงผลอย่างไรเมื่อเจอหุ้นที่ราคาพัง — ไม่ใช่หลักฐานและไม่ใช่ข้อมูลฝึก/ทดสอบ
> ทดลองระบบ ข้อมูลไม่ครบ ไม่ใช่หลักฐานว่ากฎชนะตลาด

## รูปแบบไฟล์ (`cases_template.csv`)
- บรรทัดที่ขึ้นต้นด้วย `#` = คำอธิบาย (ถูกข้ามตอนอ่าน)
- คอลัมน์: `case_id, ticker, date, price, note` — `date` = YYYY-MM-DD, `price` = ราคาปิด (USD)
- ใส่เองด้วยมือได้เลย 1 แถวต่อ 1 จุดราคา; เคสหนึ่งมีได้หลายแถว (หลายวัน)
- อ่านด้วย `python3 -m stress_cases.load` (ตรวจรูปแบบและแสดงสรุป)
