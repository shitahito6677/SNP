## 4) ทำไมไม่ผ่าน (สิ่งที่ล้มเหลว)
- **หุ้นถูก (value)** แพ้ตลาดเฉลี่ยทุกรูปแบบในช่วง 2017–2022 — ยุคที่หุ้นเติบโต/หุ้นใหญ่มากนำตลาด; ใส่ value ในคะแนนรวมทำให้แย่ลงเสมอ
- **Piotroski เดิม** เหลือหุ้นแค่ ~13 ตัว เป็นหุ้นวัฏจักรที่แกว่งแรง (เรือสำราญขาดทุนหนักปี 2019–20, สายการบินฟื้นแรงปี 2020–21)
- **คุณภาพกำไร (accruals ต่ำ, ROIC, gross profit)** ดีช่วงตัดสิน แต่แพ้ช่วงแรก → ผูกกับช่วงเวลา
- **สัญญาณราคา** เดี่ยวไม่เด่นในหุ้นใหญ่ช่วงนี้; ความผันผวนต่ำดีมากช่วงแรกแต่ไม่ต่อเนื่อง
- **คุมความเสี่ยงตลาด** ลดการขาดทุนได้ แต่วิกฤตโควิดสั้นและฟื้นเร็ว → ออกช้า เข้าช้า เสียโอกาส
- **ML** ได้แค่เท่าตลาดเฉลี่ย และกฎที่สกัดได้เปลี่ยนตัวแปรหลักแทบทุกปี
- **ข้ามตลาด:** factor คลาสสิก (value, profitability, investment, momentum) เป็นบวกในระยะยาวทั้ง 6 ตลาด/ยุค (Ken French) — มีอยู่จริงแต่อ่อนเกินกว่าจะชนะขาดรอยในหุ้นใหญ่สหรัฐช่วงนี้

## 5) held-out, ข้ามตลาด และ top-1500
- **held-out:** ไม่ถูกใช้ (ล็อกทางเทคนิคใน `lib/guard.py`) — ตัวเชื่อม sandbox ก็ไม่ให้คะแนนหลัง 2023-06-30
- **round 007 (top-1500, ⚠️ เสี่ยง survivorship สูง — ห้ามใช้เป็นหลักฐานหลัก):** ไม่มีรายชื่อ S&P 400/600 ย้อนหลังที่ตรวจได้ จึงใช้ 1,500 บริษัทใหญ่สุด
  ตาม market cap; ความครอบคลุมราคาช่วงตัดสินต่ำกว่า S&P 500 เฉลี่ย 14.2 จุด (p < 0.001 ทุกปี); บริษัทที่ออกไปแล้วมีราคาแค่ 19.5% (S&P 500: 42.7%);
  ไม่มีสเปกใดผ่าน S1 → ผู้ใช้สั่งหยุดงานส่วนนี้ (`rounds/round_007/RESULTS.md`)

## 6) ข้อจำกัดและความเสี่ยง
- **Survivorship bias:** ราคาจาก Yahoo ไม่มีหุ้นที่ถูกซื้อ/ล้มละลายจำนวนมาก (ช่วงต้นขาด 20–31% ของ S&P 500) → ผลดูดีเกินจริง; เทียบกับ SPY เอียงเข้าข้างเรา
- **ลองมาก:** 125 trial → ต้องหักส่วนลดทางสถิติมาก (DSR)
- **ช่วงตัดสินสั้นและพิเศษ:** 6 ปี (2017–2022) มีโควิดและยุคหุ้นใหญ่มากนำตลาด
- **held-out มีแค่ 3 รอบเต็ม** — แม้ใช้ก็บอกได้แค่ทิศทาง
- **ข้อมูล:** กลุ่มอุตสาหกรรมเป็น SIC (ไม่ใช่ GICS), ไม่รวมกลุ่มการเงิน, จำนวนหุ้นจาก 10-K อาจคลาดเคลื่อนหลังการควบรวม
- **บั๊กที่พบและแก้ระหว่างทาง (ทุกครั้งรันใหม่และบันทึก):** market cap/split 3 จุด (v1), งบปีก่อนหยิบแถวว่าง, วันหยุดในสัญญาณราคา, ค่า missing ของ Ken French,
  pool ของ top-1500 ตกหล่น, split และราคาหายแบบเงียบ — รายละเอียด `autorun/DEVIATIONS.md`, `../experiments/log.md`

## 9) อภิธานศัพท์
| คำ | ความหมายง่าย ๆ |
|---|---|
| **S&P 500** | ดัชนีหุ้นใหญ่ ~500 บริษัทของสหรัฐ |
| **universe** | กลุ่มหุ้นที่กฎเลือกได้ (ที่นี่ = สมาชิก S&P 500 ณ วันนั้น ไม่รวมกลุ่มการเงิน) |
| **ตลาดเฉลี่ย (EW, equal-weight)** | ซื้อทุกหุ้นใน universe เท่า ๆ กัน — ตัวเทียบหลัก |
| **SPY** | กองทุน ETF ที่เลียนแบบ S&P 500 ตามขนาดบริษัท |
| **CAGR (กำไรต่อปี)** | ผลตอบแทนเฉลี่ยทบต้นต่อปี |
| **Max drawdown (ขาดทุนหนักสุด)** | มูลค่าพอร์ตลดลงจากจุดสูงสุดมากที่สุดเท่าไร |
| **Sharpe** | กำไรส่วนเกิน (เหนือดอกเบี้ยพันธบัตรระยะสั้น) ต่อความผันผวน — ยิ่งสูงยิ่งได้กำไรต่อความเสี่ยงมาก |
| **bps** | 1 bps = 0.01% — ใช้บอกค่าซื้อขาย (10 bps = 0.10% ต่อการซื้อหรือขาย) |
| **rebalance** | วันจัดพอร์ตใหม่ (ที่นี่ส่วนใหญ่ = วันทำการสุดท้ายของ มิ.ย.) |
| **ช่วงตัดสิน / ช่วงประกอบ** | ก.ค. 2017 – มิ.ย. 2023 ใช้ตัดสิน; ก.ค. 2011 – มิ.ย. 2017 ใช้ประกอบ (ข้อมูลหายมากกว่า) |
| **held-out** | ข้อมูลช่วงท้าย (ก.ค. 2023 เป็นต้นไป) ที่ล็อกไว้ห้ามดู — เหมือนข้อสอบจริงที่ยังไม่เปิด |
| **freeze** | ล็อกสเปกกฎก่อนเปิด held-out ครั้งเดียว — ทำเฉพาะกฎที่ผ่าน S1–S6 |
| **trial** | การลองตั้งค่า 1 แบบบนข้อมูล — ยิ่งลองมาก โอกาสเจอผลดีโดยบังเอิญยิ่งสูง |
| **DSR (Deflated Sharpe Ratio)** | Sharpe ที่ถูกหักส่วนลดตามจำนวนการลอง → ความน่าจะเป็นว่าผลดีไม่ใช่ดวง (ต้อง ≥ 0.95) |
| **S1–S7** | เกณฑ์ชนะขาดรอย: S1 ชนะตลาดเฉลี่ยและ SPY ชัดเจน (Sharpe +0.15, กำไร +2 จุด/ปี, ขาดทุนไม่แย่กว่า 5 จุด ที่ต้นทุน 0.10% และ 0.25%) · S2 ชนะ ≥ 70% ของช่วง 3 ปีที่เลื่อนไป · S3 DSR ≥ 0.95 · S4 ตั้งค่าใกล้เคียงก็ยังผ่าน · S5 ได้ผลทิศเดียวกันใน ≥ 4/6 ตลาด/ยุค · S6 ถือ ≥ 30 ตัว · S7 ผ่าน held-out |
| **ระดับ A / B / C** | A = ผ่านทุกข้อ; B = ผ่าน S1–S4 แต่ตก S5 หรือ S7; C = อื่น ๆ (ไม่ผ่าน) |
| **point-in-time** | ใช้เฉพาะข้อมูลที่ "มีอยู่จริง ณ วันนั้น" (วันยื่นงบจริง, ตัวเลขที่ยื่นครั้งแรก) — กันการมองอนาคต |
| **survivorship bias** | ข้อมูลมีแต่บริษัทที่รอดถึงวันนี้ ทำให้ผลในอดีตดูดีเกินจริง |
| **walk-forward** | เลือกจากช่วงแรก แล้วดูผลช่วงหลังที่ไม่ได้ใช้เลือก |
| **market cap** | มูลค่าบริษัท = ราคาหุ้น × จำนวนหุ้น |
| **cap-weight / inverse-vol** | ถือตามขนาดบริษัท / ถือมากในหุ้นที่ราคาแกว่งน้อย |
| **sector-neutral** | จัดอันดับภายในกลุ่มอุตสาหกรรมเดียวกัน ไม่ให้กระจุกกลุ่มใดกลุ่มหนึ่ง |
| **BM (book-to-market)** | มูลค่าทางบัญชี ÷ มูลค่าตลาด — สูง = หุ้น "ถูก" (value) |
| **F-score (Piotroski)** | คะแนน 0–9 วัดความแข็งแรงของงบ (กำไร, เงินสด, หนี้, สภาพคล่อง, ประสิทธิภาพ) |
| **accruals** | ส่วนต่างระหว่างกำไรทางบัญชีกับเงินสดจริง — ต่ำ = กำไรเป็นเงินสดจริง (คุณภาพกำไรดี) |
| **ROIC / gross profitability** | กำไรจากการดำเนินงานต่อเงินทุน / กำไรขั้นต้นต่อสินทรัพย์ — วัด "คุณภาพ" |
| **shareholder yield** | (ปันผล + ซื้อหุ้นคืน − ออกหุ้นใหม่) ÷ มูลค่าตลาด — เงินที่คืนผู้ถือหุ้น |
| **momentum 12-1** | ผลตอบแทน 12 เดือนที่ผ่านมาโดยเว้นเดือนล่าสุด — "แรงส่ง" ของราคา |
| **factor (HML / RMW / CMA / MOM)** | พอร์ตมาตรฐานของ Ken French: หุ้นถูก−แพง / กำไรดี−แย่ / ลงทุนน้อย−มาก / ชนะ−แพ้ในอดีต |
| **overlay** | กฎจังหวะเข้า-ออกตลาด (เช่น ถือเงินสดเมื่อราคาต่ำกว่าเส้นเฉลี่ย 10 เดือน) |
| **SEC / XBRL / 10-K / CIK / SIC** | ก.ล.ต.สหรัฐ / รูปแบบข้อมูลงบที่เครื่องอ่านได้ / งบประจำปี / เลขประจำตัวบริษัทของ SEC / รหัสอุตสาหกรรม |
| **PREREG** | เอกสารเกณฑ์ที่เขียนและ commit ก่อนรัน เพื่อกันการปรับเกณฑ์หลังเห็นผล |
| **adapter / sandbox** | ตัวเชื่อมผลของ Model A เข้ากับ web simulator ของผู้ใช้ (เดโม ไม่ใช่หลักฐาน) |
