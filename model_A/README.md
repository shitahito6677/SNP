# Model A — Fundamental rule-based (S&P 500)

> **สรุป 5 บรรทัด**
> 1. **ชนะตลาดขาดรอยไหม: ไม่** — จาก 115 การทดลอง ไม่มีกฎใดผ่านเกณฑ์ที่ล็อกไว้ก่อนรันครบทุกข้อ
> 2. **ระดับผล: C ("ไม่ผ่าน") ทุกกฎ** — 6 กฎชนะ EW/SPY ในช่วงตัดสิน แต่ไม่ผ่านการทดสอบว่า "ไม่ใช่โชค" (DSR สูงสุด 0.613 < 0.95)
> 3. **ตัวเลขหลัก:** ดีที่สุด (low accruals, cap-weight) Sharpe 0.929 vs EW 0.640 / SPY 0.681 ในช่วง 2017–2022 — แต่แพ้ EW ในช่วง 2011–2016
> 4. **ข้อควรระวัง:** survivorship bias (ข้อมูลขาดหุ้นที่ล้มหาย), ช่วงตัดสินสั้น (6 ปี), held-out ยังไม่ถูกใช้ (ไม่มีกฎที่ผ่านถึงขั้นนั้น)
> 5. **ส่วนเพิ่ม:** ขยายเป็น universe top-1500 (round 007) ก็ไม่ผ่าน และติดป้าย "เสี่ยง survivorship สูง"; มีเดโม adapter ใน sandbox (ไม่ใช่หลักฐาน)
> 6. **สิ่งที่ได้:** pipeline ข้อมูล point-in-time ที่ตรวจแล้ว + หลักฐานว่า factor คลาสสิกในหุ้นใหญ่ S&P 500 ช่วงนี้ไม่แรงพอจะชนะแบบทนทาน

## อุปมา
เหมือนการคัดนักวิ่งจาก 93 วิธี — มีบางวิธีที่เลือกได้นักวิ่งชนะการแข่งขันปี 2017–2022 แต่เมื่อดู (1) ผลแข่งปี 2011–2016 (2) ความจริงที่ว่า
ถ้าลองเลือก 93 แบบ ต้องมีบางแบบชนะโดยบังเอิญแน่ ๆ — ก็ยังไม่มีวิธีไหนที่เชื่อได้ว่า "เก่งจริง" ไม่ใช่ "ดวงดี"
