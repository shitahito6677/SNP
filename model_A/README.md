# Model A — กฎเลือกหุ้นจากงบการเงิน (S&P 500)

> ## สรุปสั้น ๆ
> 1. **ผลคือ "ไม่ผ่าน" — ทุกกฎอยู่ระดับ C** จากการลองทั้งหมด 115 ครั้ง ไม่มีกฎใดผ่านเกณฑ์ "ชนะตลาดขาดรอย" ที่ล็อกไว้ก่อนเริ่ม
> 2. มีบางกฎที่ **ช่วง 2017–2022 ดูดีกว่าตลาด** (กำไร ~17–19% ต่อปี เทียบตลาดเฉลี่ย ~12.5%) แต่ **ไม่ผ่านการทดสอบว่าไม่ใช่โชค** และ **ช่วง 2011–2016 กลับแพ้ตลาด**
> 3. ข้อมูลมีจุดอ่อน: หุ้นที่ล้มหายไปแล้วหาราคาไม่ได้ (survivorship bias) → ผลทุกตัวน่าจะดูดีเกินจริง
> 4. **ยังไม่ใช้ข้อมูลช่วงสุดท้าย (held-out ตั้งแต่ ก.ค. 2023)** เพราะไม่มีกฎที่ผ่านถึงขั้นนั้น — เก็บไว้ใช้ทดสอบกฎในอนาคต
> 5. มีตัวเชื่อมกับ web simulator แบบ **ทดลองระบบ** (`export/`) — *ทดลองระบบ ข้อมูลไม่ครบ ไม่ใช่หลักฐานว่ากฎชนะตลาด*

## อุปมา
เหมือนคัดนักวิ่งด้วย 115 วิธี บางวิธีเลือกได้นักวิ่งที่ชนะการแข่งปี 2017–2022 แต่ (1) นักวิ่งกลุ่มเดียวกันแพ้ในปี 2011–2016 และ
(2) ถ้าลองคัดตั้ง 115 แบบ ย่อมมีบางแบบชนะเพราะ "ดวง" — เครื่องมือทางสถิติ (DSR) บอกว่าผลที่เห็นยังแยกจากดวงไม่ได้ จึงยังเชื่อไม่ได้ว่าเก่งจริง
